# Color Vision Check

A free colorblind test in your browser: dot circles with hidden numbers, then a color line-up test.
Takes about 5 minutes and tells you whether your color vision is normal, and if not which kind of
colorblindness you have (red-weak, green-weak or blue-weak) and how strong it is.

**Take it:** https://acherchu.github.io/color-vision-check/

It's a screen test, so it's a good guide but not a medical diagnosis.
